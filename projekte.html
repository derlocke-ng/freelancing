kiwi-server

Baut die Maschinen eines Kiwi Networks: Aus einer fleet.yaml entstehen pro Host ein Rollen-Skript, eine Ignition- oder Preseed-Konfiguration und ein ISO, das sich unbeaufsichtigt installiert. Rollen für VPN-Zugangspunkt, LAN-Gateway und Cloud-Knoten; CLI und GTK4-App.

  • Python
  • Jinja2
  • Bash
  • Butane / Ignition
  • Preseed
  • Docker Compose
  • WireGuard
  • GTK4

kiwi-fox

Isolierte Browser-Profile in rootless Podman: Jedes Profil hat eigenen Speicher, eigenen Proxy-Ausgang, eigenen DNS-Resolver mit Werbefilter und einen festen Fingerprint. Ein Gateway-Container mit nftables-Default-Drop ist der einzige Weg nach draußen – fällt er aus, gibt es keine Route.

  • Python 3.12
  • Pydantic
  • Podman (rootless)
  • nftables
  • SOCKS5
  • GTK4
